# 💳 Credit Card Fraud Detection System

An end-to-end Machine Learning project that detects fraudulent credit card transactions using advanced ML techniques and an interactive web application.

---

## 🚀 Live Demo
👉 https://chandkund-credit-card-fraud-detection-appapp-sdause.streamlit.app/

---

## 📌 Problem Statement

Credit card fraud is a major issue in the financial industry. The challenge is to accurately detect fraudulent transactions from highly imbalanced datasets while minimizing false positives.

---

## 💡 Solution

This project builds a fraud detection system using:

- Machine Learning (XGBoost)
- Imbalance handling (SMOTE)
- Explainable AI (SHAP)
- Interactive UI using Streamlit
